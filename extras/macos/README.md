# App macOS facoltativa

La dashboard di opencode-lens in una finestra nativa, con Dock, notifiche e avvio al login. Facoltativa: la lens funziona identica senza.

```bash
bash ~/Applications/opencode-lens/extras/macos/app.sh install     # oppure: uninstall | test | build --out DIR
```

Requisiti, notifiche, sicurezza, disinstallazione e sviluppo: [docs/app-macos.md](../../docs/app-macos.md) ([English](../../docs/en/app-macos.md), [Français](../../docs/fr/app-macos.md)).
